The Blood of Dawnwalker arrives **September 3, 2026** on **PlayStation 5**, **Xbox Series X|S**, and **PC (Steam)**. Pre-orders are open now. There are several editions with different bonuses and a wide price spread, so here's a clear comparison to help you decide.

## Release date

- **Launch:** September 3, 2026 — same day on all platforms.
- No confirmed early-access window beyond standard pre-load.

## Editions compared

| Edition | Price (USD) | What you get |
| --- | --- | --- |
| **Standard** (digital/physical) | $69.99 | Base game |
| **Eclipse** (digital) | $79.99 | Base game + digital world compendium, digital comic, digital soundtrack |
| **Day One** (physical) | Retail | Base game + SteelBook case + world map |
| **Collector's** (physical) | $199.99 | Eclipse + Day One bonuses + physical compendium + 9″ Coen figurine |

## Which should you buy?

- **Most players → Standard Edition.** You get the full game; nothing in the upgrades affects gameplay.
- **Lore and music fans → Eclipse Edition.** The +$10 buys the soundtrack, comic, and an in-world compendium, which is reasonable if you enjoy the worldbuilding.
- **Collectors → Collector's Edition.** Only worth it if you specifically want the physical figurine and SteelBook; otherwise the price jump is steep.
